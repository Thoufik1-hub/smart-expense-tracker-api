# AI Usage Notes

## 1. AI Assistance Used

I used AI tools (ChatGPT) during the development of this project for:
- Understanding project requirements
- Designing REST API structure
- Debugging errors during development
- Improving README documentation

## 2. AI Generated vs Developer Written Code

AI was used for guidance, code suggestions, and troubleshooting.

I personally implemented and verified:
- Express.js server setup
- Expense API endpoints
- CRUD operations
- API testing using Postman
- GitHub repository setup

I reviewed and modified AI suggestions according to the assignment requirements.

## 3. Validation and Testing

I tested the application using:
- Postman
- PowerShell curl commands

The following functionalities were verified:
- Adding expenses
- Viewing all expenses
- Updating expenses
- Deleting expenses
- Server startup

## 4. AI Suggestions Not Used

Some AI suggestions were not implemented because:
- Database integration was not required for this assignment.
- The assignment required a simple local data storage approach.
- Extra complexity was avoided to keep the solution simple and maintainable.
